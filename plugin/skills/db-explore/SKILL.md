# DB 구조 파악

목표는 사용자가 처음 보는 DB라도 **핵심 테이블 몇 개와 그 관계**를 한눈에 알게 하는 것이다.
테이블을 전부 나열하지 말고, 업무 흐름(무엇이 무엇을 거쳐 어디에 기록되는지)으로 묶어서 설명한다.

## 준비

db-scout MCP 도구가 필요하다(이름 앞에 플러그인 접두사가 붙을 수 있다). `list_tables`가 없으면 시작하지 말고 설치 방법을 알려 준다.

```
/plugin marketplace add 98Woonho/db-scout-mcp
/plugin install db-scout@db-scout-mcp
```

## 진행 순서

### 1. 어느 DB인지 확인
`list_connections`로 접속 목록을 본다. 접속이 여러 개인데 사용자가 어느 것인지 말하지 않았다면 묻는다.
`demo: true`면 내장 샘플 DB(Sakila, DVD 대여점)라는 것을 답변에 밝힌다.

### 2. 전체 목록 훑기
`list_tables`로 테이블·뷰와 행 수를 본다. 행 수로 성격을 짐작하는 데서 출발한다.

- 행이 많은 테이블은 대개 **일어난 일의 기록**(주문, 결제, 대여, 로그)이다.
- 행이 적은 테이블은 대개 **기준 정보**(분류, 코드, 지점, 언어)다.
- 뷰(type에 VIEW)는 다른 테이블을 조합한 것이므로 따로 표시한다.
- 행 수가 "통계 추정치"면 숫자 앞에 "약"을 붙인다.
- 테이블이 50개를 넘으면 이름 앞부분(접두사)으로 무리를 짓고, 어느 영역이 궁금한지 사용자에게 묻는다.

### 3. 핵심 테이블만 자세히
`describe_table`은 **핵심 테이블 5~8개에만** 쓴다. 고르는 기준:
행이 가장 많은 기록 테이블, 그 기록이 가리키는 테이블(`references`), 다른 테이블이 많이 가리키는 테이블(`referencedBy`).
전부 describe하면 대화 공간을 낭비하고 요약도 흐려진다.

### 4. 관계 그리기
관계는 `describe_table`의 `references`·`referencedBy`(외래키)에 있는 것만 쓴다.
컬럼 이름이 같다는 이유만으로 연결됐다고 단정하지 않는다. 외래키 없이 추정한 연결은 "추정"이라고 표시한다.
두 테이블이 어떻게 이어지는지 묻는 질문이면 `find_join_path`로 확인한다. 경로가 여러 개면 각각 무슨 뜻인지 설명한다
(예: film → language는 원어(language_id)와 원작 언어(original_language_id) 두 가지).

### 5. 값이 무슨 뜻인지 모를 때만 들여다보기
코드 값(예: rating의 'PG-13', active의 1/0)의 의미가 불분명할 때만 `profile_column`이나 `sample_rows`(3행 정도)로 확인한다.
구조 설명에는 데이터 행이 거의 필요 없다.

### 6. 특정 개념을 찾는 질문
"결제는 어디 있어?"처럼 위치를 묻는 질문이면 `search_schema`에 영어 이름·줄임말·한국어를 함께 준다
(예: `payment pay amount 결제`). 테이블·컬럼 이름은 대부분 영어다.

## 답변 형식

1. **한 줄 요약**: 어떤 업무의 데이터인지. 예) "DVD 대여점 데이터입니다. 영화 재고를 고객에게 빌려주고 결제를 받는 흐름이 기록돼 있습니다."
2. **영역별 표**: 영역 | 테이블 | 행 수 | 역할. 예) 대여 흐름 / 기준 정보 / 사람(고객·직원) / 뷰
3. **관계도**: 핵심 테이블만 담은 mermaid `erDiagram`. 관계는 외래키 기준, 컬럼은 키와 대표 컬럼 2~3개만.
4. **알아 둘 점**: 개인정보로 가려지는 컬럼(`masked`)이 있으면 "조회 결과에서 가려진다"고 한 줄. 이상한 점(빈 테이블, 외래키 없는 테이블)이 있으면 짧게.
5. **이어서 물어볼 만한 질문** 2~3개. 예) "카테고리별 매출 순위", "가장 많이 빌린 고객"

## 하지 않는 것

- 모든 테이블을 describe하거나 컬럼을 전부 나열하지 않는다(사용자가 특정 테이블을 물으면 그 테이블은 자세히).
- 가려진 개인정보 값을 보려고 다른 방법으로 다시 조회하지 않는다.
- 도구 결과에 없는 테이블·관계·행 수를 지어내지 않는다.
